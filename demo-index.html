①スタッフを選ぶ → ②書いて追加 → ③一覧で確認。

デモを開く → シフト

シフト・希望休

少人数の店・教室向け／シフトと希望休のやり取りが散らかる

①週を選ぶ → ②マスをタップで切替 → ③メモをコピー。

デモを開く → 予約

簡易予約・受付

美容院・整体・個人サロン向け／電話予約のメモが取りこぼしやすい

①予約を追加 → ②来店に変更 → ③完了まで進めます。

デモを開く → 在庫

①＋／−で増減 → ②要発注（オレンジ）を確認 → ③品目追加。
